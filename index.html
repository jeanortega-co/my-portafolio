SIMULACIÓN FINTECH

FastBank Oficial

02

Plataforma bancaria digital simulada con arquitectura cliente-servidor y asientos contables balanceados. Incluye registro con validación colombiana, verificación por correo, autenticación JWT y Passkeys, transferencias idempotentes, tarjetas, FastCredit por puntaje, bolsillos de ahorro, inversiones simuladas y panel administrativo.

  • Vue 3
  • Pinia
  • Node.js
  • Express
  • SQLite
  • JWT / WebAuthn
  • Tailwind CSS
Detalles técnicos
  • Operaciones transaccionales con asientos contables balanceados y claves de idempotencia.
  • Recuperación mediante hashes SHA-256 y FastCredit por niveles de puntaje de 60 a 90.
  • Entorno de simulación financiera: no procesa dinero real ni se conecta a redes bancarias.

E-COMMERCE · MVP

XrteShop

03

MVP de marketplace multivendedor que conecta compradores con vendedores independientes. Incluye catálogo con filtros, carrito persistente, cuentas de usuario, paneles de vendedor y administración, importación de productos mediante la API oficial de Mercado Libre y pagos Wompi en sandbox.

  • Python
  • Flask
  • PostgreSQL / Neon
  • SQLite
  • JavaScript
  • API Mercado Libre
  • Wompi (Sandbox)
Detalles técnicos
  • Flask con PostgreSQL en Neon; SQLite para desarrollo local.
  • Flujos de marketplace para compradores y vendedores, con paneles diferenciados.
  • Wompi funciona en sandbox; los pagos y liquidaciones a vendedores se registran manualmente en esta etapa MVP.
